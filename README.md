
# Core Wallet Maintenance Tools

Platform-independent tools to extract and re-import **private descriptors** in modern descriptor wallets of **Bitcoin Core** and **Namecoin Core**.

## Structure

- **[Bitcoin/](Bitcoin/)** – Tools for Bitcoin Core  
- **[Namecoin/](Namecoin/)** – Tools for Namecoin Core  

Please open the respective folder and follow the instructions in the README there.
